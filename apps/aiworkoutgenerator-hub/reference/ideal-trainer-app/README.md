# Ideal Trainer App Reference

This directory contains the ideal/example implementation of the trainer app workflow.

## Purpose

This reference implementation demonstrates best practices for:

- Input handling and validation
- AI prompt engineering for structured output
- Output parsing and validation
- Error handling
- Workflow structure

## Structure

Please paste your ideal trainer app files here. The structure should include:

- Input schemas/types
- Prompt templates
- Flow implementations
- Output parsing/validation

Once files are added, we can review and cherry-pick best practices to improve the current implementation.
