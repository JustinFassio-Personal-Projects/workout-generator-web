## Notes

- Categories are stored as arrays, allowing equipment to belong to multiple categories
- `primary_category` provides high-level grouping (Free Weights, Machines, Cardio, etc.)
- `sub_category` provides more specific classification (Barbell, Dumbbells, Rowing, etc.)
- `categories` array provides multi-dimensional classification for filtering and search
- `display_order` determines default sorting order
- Equipment IDs are used as document IDs in Firestore
